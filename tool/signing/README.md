# Chiave di firma (sviluppo)

`app.jks` è una chiave **pubblica di sviluppo**, salvata qui apposta perché
ogni nuova versione dell'APK si installi sopra la precedente senza
disinstallare. Va bene per installare l'app sul proprio telefono,
**non** per pubblicarla sul Play Store.

Alias: `app` · password: in `password.txt`.
